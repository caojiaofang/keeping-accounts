# 独立月预算

2026-11-07 按需求纠正预算模型。主要入口为「月度预算」及「设置月预算」，替代原先以持续收入分配、周期预留和储蓄为中心的设置流程。

## 使用规则

- 每个账本、每个月独立保存项目名称及预算金额，可以新增项目、修改名称和额度。总支出预算为支出项目额度之和，不要求先填写计划收入。
- 新月份默认未设置。点击「沿用上月预算」只把上月已保存项目及额度填入草稿，保存后才生效，不复制账单、消费金额、资金流水或目标。
- 手动记账时可选择账单日期所在月份的预算项目，也可不关联。补记账单按实际账单月份归集，修改日期或账本时重新读取可选项目。
- 项目已用为该月关联的有效支出合计。剩余为预算减已用；结果小于零时显示超支绝对金额。调高或调低额度立即重新计算，零额度合法。
- 总预算已用包括未关联支出；未关联支出单独列出，可以打开原账单补选预算。收入不抵减支出，不重复创建消费。
- 所有有效家庭成员与创建者均可创建、修改、删除家庭月预算，支持删除他人创建的项目或整个月预算。退出／被移出成员无权操作；个人账本仍仅本人可用。操作写入共同账本动态。
- 单项删除需保存预算后生效；整月删除需在页面确认。相关消费仅解除所选月份的预算关联，原账单、其他月份、实际存入与期初记录保留，派生用款作废恢复资金余额。历史月份预算仍只读。

## 接口与存储

接口前缀为 `/api/v1/books/{book_id}/budgets`：

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/monthly/{month}` | 读取已保存月预算；不自动把旧持续方案当成已设置 |
| PUT | `/monthly/{month}` | 完整保存该月项目，正文为 `requestId`、`version`、`plan` |
| DELETE | `/monthly/{month}` | 删除整个月预算，正文为 `requestId`、`version`，保留原账单 |
| GET | `/monthly/{month}/execution` | 读取当月额度、关联消费及未关联消费 |

新增月份的 `version` 为 0；更新使用读取到的月份版本。账本排他锁串行化成员变更、预算修改和记账；版本不符返回 409。相同账号以原请求 ID 和正文重试，不重复保存；同一个请求 ID 不能换正文或换成员重放。

迁移 `0009_budget_deletion` 为月份增加 `is_deleted`。整月删除保留月份和递增版本，接口返回 `state: not_set`、空方案及正整数版本。重新创建时须使用该删除版本，不重新从 0 开始；这样删除前的旧保存、旧删除请求不会覆盖重建后的预算。删除请求重放先验证当前成员资格，再校验原请求 ID 与正文。项目删除、整月删除、账单解除关联及派生用款恢复均在同一事务中完成。

记账创建和修改接口支持可选 `budgetItemId`（项目 UUID 或 null）及 `budgetLinkVersion`。账单与归集在同一事务中保存，项目不属于该账单月份、跨账本、失权或关联版本冲突都会回滚账单写入。不传 `budgetItemId` 时维持既有调用行为，修改／删除账单仍触发原关联同步。新前端读取原关联版本，显式传项目或 null。

复用 `budget_months` 快照及 `budget_entry_links`，新迁移 `0008_monthly_budget` 为预算版本新增 `monthly_only` 标记，并调整旧方案部分唯一索引。月预算版本不参与旧持续方案的后续月份选取；保存只更新指定月快照。原方案、已确认月份、原账单和已有预留／储蓄记录保留；原预留和储蓄仍按旧资金语义读取，不计入新的支出预算合计。旧接口供兼容调用保留，资金与目标修改仍沿用原创建者权限。
