# 正式上线：20261026T050441Z

2026-10-26（北京时间）发布并完成真实 API 与浏览器登录验收。管理页面为 `https://mjzs.zf-yun.cn`，管理接口前缀为 `/prod-api`；小程序继续使用 `/api/v1`。

## 本次功能

- 独立 `admin/` 项目，Vue 3 + Element Plus + TypeScript + Vite，提供登录、数据概览、用户查询、账本和共享成员只读查询。
- 管理员采用服务端配置的独立账号、Argon2 密码摘要及 Redis 会话，不复用微信用户登录态。凭证通过 Secure、HttpOnly、SameSite=Strict Cookie 保存，退出撤销当前凭证，账号或摘要变更后旧会话失效。
- 支持数据库分页、名称与 ID 查询、账本类型和状态筛选、用户账本跳转、错误重试、空列表、复制 ID 和手机窄屏导航。
- 业务查询不返回 OpenID、账单正文、金额、预算、聊天内容及邀请密钥，也不提供业务写入操作。
- 公共 Nginx 根路径提供独立 Web 静态容器，管理接口与原小程序接口原样代理到 FastAPI。
