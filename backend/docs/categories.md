# 公共分类与账本自定义分类

现有 12 个支出分类和 5 个收入分类作为公共分类，ID、名称、图标及收支类型固定。公共分类不提供用户修改、删除功能。

每个账本可以新增独立的自定义分类，按收入、支出分开管理。同一账本、同一收支类型的有效分类不能重名，也不能与对应公共分类同名。名称去除首尾空格后为 1 至 12 个字；当前支持修改名称，收支类型创建后固定。不同账本可以使用相同名称。

个人账本仅本人可维护；共享账本所有有效成员可维护。退出、被移出或账本解散后不可继续访问。新增、改名、删除和记账共用账本行锁，修改和删除校验分类版本；共享分类变更保留操作记录。

## 使用入口

- 「我的 → 收支分类」：选择账本与收支类型，查看固定公共分类，并新增、修改或删除本账本的自定义分类。
- 「记一笔 / 编辑账单 → 管理分类」：管理完成后返回原记账表单，选择公共分类或所选账本的有效自定义分类。
- 智能记账接收当前账本有效分类目录，草稿核对时也可选择自定义分类；服务端再次检查分类归属与收支类型。
- 明细、统计、CSV 导出和消费分析按分类 ID 读取名称，不把自定义分类归入“其他”。体验模式本机保存，登录账号使用云端保存，切换账号时清理旧内存数据。

## 修改和删除的含义

改名会更新这个分类在已有账单、统计和导出中的名称。已保存的聊天回答依旧是生成时的历史快照。

删除是软删除：不删除账单、不修改金额和预算关联，保留历史分类名称与统计。新账单不能再选择已删除分类；编辑原账单时可以保留原分类。重新新增同名分类会分配新 ID，不与旧分类混合。分类不能跨账本使用，账单转移到其他个人账本时需重新选择适用分类。

## API 和迁移

- `GET /api/v1/ledger` 追加 `customCategories`，只返回有权访问账本的全部专属分类（含历史删除状态）。公共目录由客户端固定提供。
- `POST /api/v1/books/{book_id}/categories`：`id`、`type`、`name`。ID 为 `c_` 加 20 位十六进制字符；同 ID 同内容重试不会重复创建。
- `PUT /api/v1/books/{book_id}/categories/{category_id}`：`name`、`version`。
- `DELETE /api/v1/books/{book_id}/categories/{category_id}?version=...`：返回已删除分类，可安全重试。
- 公共分类改删返回 403，失权账本返回 404，版本或重名冲突返回 409，分类归属或收支类型不匹配返回 422。

新增迁移 `0010_book_categories`，只创建分类表和索引，不改写原账本与账单。上线时先备份并在目标环境执行 `alembic upgrade head`，部署配套后端后再发布新版小程序。2026-11-16 已[发布后端 `20261116T054923Z`](releases/20261116T054923Z.md)，正式库已迁移至 `0010_book_categories`，个人及共享成员的线上分类权限验收通过。开发库未升级；小程序分类管理界面尚未上传发布。
