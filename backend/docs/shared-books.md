## 使用流程

登录用户从「多人账本」创建真实共同账本，再点击「邀请家人」生成微信邀请卡片。打开卡片可以先查看账本名称、邀请者称呼和到期时间；登录并明确点击确认后才加入。成员在加入时填写自己在账本中的称呼，这不是微信认证昵称。打开分享页、恢复登录或预览均不会自动加入。

有效成员可读取共同收支、成员及历史记账人，新增本人账单、查看统计和日历、复制 CSV、使用自己的分析会话查询共同数据。创建者可以维护全部共同账单、设置预算、移出成员、转让和解散。普通成员只能修改或删除自己提交的账单，可以主动退出。

创建者修改他人记录时保留 `createdBy`，更新 `updatedBy` / `updatedAt`，并保存修改前后内容。小程序明细展示记账人及不同的最后修改人，「操作与修改记录」可分页查看变更。退出或移出保留原账单和记账人；共同账单不能转移到其他账本。解散后所有成员失去正常访问权限，服务端保留历史数据，当前没有恢复入口。

## 权限与一致性

- 用户身份只来自现有 Bearer 登录态。普通成员、非成员不能通过伪造请求提升权限，个人账本保持仅本人可见。
- 共享读取要求账本有效及成员 `active`。账本读写、成员、邀请和生命周期变更通过行锁协调，并在等待锁后用新语句复核成员状态。
- 查询快照、账单增删改、预算、操作记录、模型识别、分析查询和历史对话均检查当前权限。分析等待模型后再次检查，成员失效时不保存或返回旧分析结果。
- 成员之间共享账本数据，不自动共享彼此的聊天记录；每个人只能继续自己创建的分析会话。
- 多设备修改账单、预算和生命周期操作使用版本号防止覆盖；前端保留确认弹窗打开时的版本。失败不显示为成功，不提供离线写入。
- 小程序进入页面、保存后及下拉刷新读取云端；成员失效后，下一次刷新会清除本机当前缓存中的对应账本和记录。目前没有实时推送，已读取的离线缓存不能被跨设备即时撤回。

## 邀请配置

```dotenv
# 开发与正式环境各自生成独立的随机值，至少 32 字符。
BOOK_INVITE_SECRET=<后端专用随机密钥>
```

本地开发 `.env` 已生成该配置，不提交到 Git。正式环境已在服务器独立生成，没有复制开发密钥。签名中包含环境与小程序 AppID，开发邀请不能加入正式账本；更换密钥会使旧邀请失效。

邀请有效期七天，可重复分享给多位家人，只有创建者可以生成、重新生成或撤销。后端根据安全签名恢复同一邀请的分享凭证，数据库只保存 SHA256 摘要，不保存原文。重新生成、成员退出或移出、转让和解散均撤销现有邀请；再次加入需要有效的新邀请及用户确认。

预览与接受接口使用 POST 正文传凭证，避免将原文写入后端访问日志。预览不返回真实收支或成员列表，同一 IP 每分钟限六十次。邀请失败、过期、撤销或不属于当前环境时不加入。登录返回地址只允许白名单中的小程序页面及严格匹配的邀请路径。

## 接口

以下路径前缀 `/api/v1`，除公开预览外均要求登录。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| POST | `/books` | 新增支持 `{id, name, kind:"shared", memberName}`，同一事务建立创建者关系 |
| GET | `/ledger` | 同时返回本人个人账本和当前有效共同账本，以及共同账单 |
| GET | `/books/{id}` | 读取有权限的账本及成员 |
| GET | `/books/{id}/members` | 当前及历史成员 |
| POST | `/books/{id}/invitations` | `{id, replace}` 创建或恢复有效邀请，同一 ID 可重试 |
| DELETE | `/books/{id}/invitations/{invitationId}` | 创建者撤销邀请 |
| POST | `/book-invitations/preview` | `{token}` 公开的有限预览，不加入 |
| POST | `/book-invitations/accept` | `{token, name}` 明确确认加入，可安全重试 |
| DELETE | `/books/{id}/members/{userId}?version=<版本>` | 创建者移出普通成员 |
| POST | `/books/{id}/leave` | `{version}` 普通成员退出 |
| POST | `/books/{id}/transfer` | `{userId, version}` 转让给另一位有效成员 |
| POST | `/books/{id}/close` | `{version}` 创建者解散 |
| GET | `/books/{id}/activities?before=<记录UUID>` | 每页二十条操作和修改记录，响应末项 ID 用作下一页游标 |

`Book` 增加 `ownerId`、`currentUserId`、`kind`、`members`。成员状态为 `active` / `removed` / `left`，角色为 `owner` / `member`。创建者不能直接移出自己或退出，须先转让或解散。已失效成员无法通过旧 token 继续读取或写入共同账本。
