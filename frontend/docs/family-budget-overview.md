# 家庭预算：月度总览与入口衔接

2026-11-06，第 09 步完成。新增 `pages/budget-overview/index.vue`、共享 `FamilyBudgetCard.vue`、纯展示计算与检查脚本。首页预算卡、「我的」预算卡和家庭预算菜单进入同一总览；总览继续沿用 ledger 的当前账本／月份。需求与进度见[总计划](../../docs/家庭预算功能与分步开发计划.md)，前置能力见[状态层](family-budget-state.md)和[设置页面](family-budget-settings.md)。

## 1. 首页和“我的”

两个页面共用 FamilyBudgetCard，读取当前账本／月的真实预算状态：

- 有家庭预算：展示计划收入、已分配、待分配或超收入，以及预览／确认状态，不再用总分配减消费解释为可花金额。
- 本月未设置：保留原 Book.budget 月支出预算及原修改弹层，另提供进入家庭预算总览的入口。只有明确 not_set 才走旧预算展示，读取失败不会假装未启用。
- 读取中／失败：显示对应状态，可进入总览刷新。成员可查看总览，旧共同预算的修改仍受原创建者权限限制。

“我的”菜单与卡片同样进入总览，不再直接跳到另一份设置。总览的「仅调整此月」「调整后续方案」把 mode 参数传给同一设置页；设置页按参数进入正确范围。保存后返回按需刷新，没有另建一份首页预算缓存。

## 2. 计划与执行口径

总览使用 month execution 响应内的 budget 与 items，计划和实际来自同一次服务端执行查询，避免把另外一份查询的计划拼到执行上。读取不会确认预算、登记存入或生成付款。

计划区展示计划收入／总分配／待分配；已确认与预览明确区分，未来月份标记为未来预览。未设置月份如实展示空态、原预算与实际支出，不拿其他月方案补造历史。

实际支出分为全部、已关联和未关联，未关联也计入真实消费。按分组展开后：

| 项目类型 | 展示口径 |
| --- | --- |
| expense | 当月额度、关联实际支出、剩余额度，超支显示负号 |
| reserve/saving | 当月计划存入、实际存入、当月使用、截至今天累计可用资金 |
| 本月计划外用途 | 保留真实执行，标明本月无计划；旧分组已不存在时集中展示 |

分组只加叶子项目，不重复计算生活费父级。存入和 use 不再增加第二份消费，负的资金余额保留负号。累计资金明确不是所选历史月期末，也不是银行账户余额。

未关联支出通过独立分页 API 读取，按需加载更多，复用既有账单查看／编辑行为。用户没有编辑权时仍按原规则只读，不自动认领历史账单。选择预算用途及资金执行操作留到第 10 步项目详情提供。

## 3. 日期、权限和刷新

本月约定缴费按支出 dueDay 或 reserve 原始锚点和周期生成，闰年／月末截断只用于该期，不漂移下期日期；显示预计金额和日期，不据此断言已付款。

活动储蓄目标读取用途详情中的实际目标和缺口，按截止日排列。仅对本月执行用途中的 saving 查询目标，每次最多四个并发请求；不把客户端计划乘月份当成实际进度。部分查询失败如实提示，可刷新重试。

普通共同成员可查看预算、真实支出和目标，修改入口仅创建者显示；过去月份不提供新编辑。页面支持下拉刷新、失败重试、账号／账本／月份切换，代次检查丢弃旧响应。原记账、统计、消费日历继续使用 LedgerEntry，未修改其收支计算。
