# 家庭预算：项目执行与目标详情

2026-11-06，第 10 步完成。新增 `pages/budget-item/index.vue`、执行表单校验和检查脚本。总览展开项目后可进入详情，也可通过「全部用途（含归档）」分页查找历史项目。需求见[总计划](../../docs/家庭预算功能与分步开发计划.md)，前置能力见[总览](family-budget-overview.md)、[设置](family-budget-settings.md)及[状态层](family-budget-state.md)。

## 1. 详情与实际资金

expense 展示所选月额度、关联支出与剩余；reserve/saving 分开展示计划存入、实际存入、期初、累计已用和截至今天可用。负余额保留负号，计划不会自动变成存款，也不冒充银行账户余额。

创建者可以登记实际存入或已有储备，须填写正整数分对应金额、实际日期，并明确确认实际资金。期初只计一次。修正通过作废旧记录并登记替代记录，或只作废，保留原记录与 replacesId；派生 use 只允许从原账单或关联修改。资金记录和关联账单分页独立，汇总不只统计当前页。

归档用途仍可查看历史、资金及合法实际执行；创建新目标须先恢复用途。全部用途列表支持继续分页，不能仅凭当前月计划查找历史资金。

## 2. 支出关联与正常记账返回

选择已有支出时可切换月份、翻页；只有原记账权限允许的账单可选。选择后重新读取当前 linkVersion 和 entryVersion，确认原账单金额、日期及目标期，才提交关联。已有其他用途关联会明确提示替换；一笔支出只算原账单一次。

「正常记账后关联」使用原记账页，返回后读取新账单；仅出现一笔新支出时打开确认表单，仍须用户确认，不自动扣储备。多笔或取消时可自行选择已有账单。关联目标用款时明确选择目标期；允许晚于目标截止日支付。取消只解除预算归集并恢复 use，真实支出保留，墓碑版本不重置为 0。

关联列表和用款历史提供查看／修正原账单入口：云端复用已有带权限复核的详情，体验使用当前本地记录和原编辑页。编辑、删除、改为收入后重读执行，不在页面额外补一份支付金额。

## 3. 目标、关闭与续建

展示每一期的目标额、本期已筹集、已用于目标、本期可用、缺口／超出额与起止日。支付后仍保留筹集进度，关闭与已付款分别表达，不根据截止日自动清空钱。

创建者可建／改活动目标，关闭时明确实际结束日；关闭后定义固定，实际记录仍可追溯修正。续建日期默认在历史截止后开始，默认分配实际非负余款；用户可修改目标额、日期和分配。结转仅分配用途，不创建存入。各期历史余额不得相加当成项目总余额。

## 4. 权限、上下文与重试

页面绑定进入时的账号和账本，切换后清除旧详情、表单及迟到响应，提示从总览重新进入。隐藏期间不回填旧读取；正常记账返回后重新核对数据。管理权限变化会关闭资金／目标表单。普通成员仅可处理有权编辑的支出，不能改共同储备或目标，服务器仍作最终复核。

每次确认固定 requestId 与完整正文；保存中和响应未确认时锁住表单，重试原请求，不生成第二份资金。409 提供放弃旧表单、读取最新版本的入口。写成功但刷新失败沿用独立刷新提示；正常刷新成功后清除旧冲突／刷新错误状态。

体验模式补齐旧账单版本兼容：无版本视为初始 1，新建 version=1，编辑后递增；派生资金和关联同步版本，重复设置相同关联不重复扣钱。退出体验或登录不会上传这些数据。
