# 微信隐私保护指引填写参考

2026-11-09 根据当前代码整理。以下是填写参考，不代表微信后台已经更新或审核通过。公开联系方式、模型服务提供方及其处理规则、数据保存和删除安排需要开发者核实后填写。

## 开发者处理的信息

- **选中的照片或视频信息**：用于你在“一句话记账”中主动选择账单截图、小票等图片，识别收支金额、日期、分类和备注，生成供你核对确认的记账草稿。当前仅处理图片，不采集视频。
- **摄像头**：用于你在“一句话记账”中主动拍摄小票、账单等图片，识别收支信息并生成供你核对确认的记账草稿。仅在你选择拍照时使用。
- 平台如提供“用户主动填写的信息”等匹配选项，补充账号昵称、收支记录、账本、预算和助手对话的实际用途。不要把手动设置昵称写成获取微信昵称，也不要增加未使用的手机号、位置、麦克风或“相册（仅写入）”能力。

## 第三方插件及 SDK

当前 manifest 未配置微信第三方插件，uniStatistics 已关闭；普通 Vue、Pinia 等运行依赖不等同于采集数据的第三方 SDK。

助手会通过服务端 API 向模型服务发送必要文字、图片及上下文。这不是小程序端接入模型 SDK，仍需在补充说明中披露实际接收方、信息种类、目的和处理规则。sub2api 是网关软件名称，模型名称也不是服务提供方的主体名称；不能据此填造主体或隐私政策链接。需核实上游留存、转发及数据处理情况，不能承诺第三方不保存或绝不对外提供。

## 联系方式、存储和使用规则

- 联系方式：填写开发者实际维护、可以公开的邮箱或其他联系渠道，用于查询、复制、更正、删除、注销申请和投诉。不能填写占位联系方式。
- 当前仅有退出登录，没有自助账号注销功能。退出登录不会删除云端账号或账单；如采用人工注销，需要落实邮箱受理和处理流程，再承诺相应办理期限。
- 当前代码没有对全部云端账号、账单、预算和分析对话按固定天数自动清理的机制。不要直接填写 30、180 或 365 天。先检查存储期限下拉菜单；如可选择说明式期限，可按实际保存与删除安排填写；如仅允许固定天数，需先确定并落实对应清理安排。
- 图片不在墨记业务数据库或磁盘持久保存；选图产生的本地临时文件由微信管理。模型服务端的留存规则需另行核实，不能用“不在墨记服务端保存”代表所有接收方均不保存。
- 用途变更告知方式可填“通过小程序内显著弹窗告知，并在获得你的明示同意后使用”；实际发生变更时须落实对应的告知与同意流程。

## 补充文档应说明的事实

1. 微信登录用于识别账号；用户可主动设置昵称。不会因此获取微信头像、微信昵称或手机号。
2. 登录后的账本、账单、预算和消费分析对话保存在云端；本地体验记录不会自动上传。
3. 智能记账会将本轮文字、主动选择的图片、最近必要对话和待确认草稿发送给模型服务。图片在服务端去除元数据后用于识别；点击确认才保存账单。
4. 记账对话只在当前页面保留；消费分析对话有云端历史，两者的存储规则不同。
5. 消费分析按需向模型服务发送统计和必要明细；按记账人查询时还会发送相关成员显示名和账本内标识。共同账本内信息会向有权限的成员展示。
6. 补充实际开发者联系方式、服务提供方主体及政策链接、存储期限和删除安排，核实与正文一致后再导出 UTF-8 `.txt` 上传。

## 图片问题修复与验证

选图前通过 `getPrivacySetting` 查询状态；需要授权时展示指引入口，用户通过微信原生 `agreePrivacyAuthorization` 按钮同意后才继续选图。不在启动或登录时请求图片授权。后台未声明能力时，客户端无法代替后台修复。

后台需完整填写并提交更新，检查审核和生效状态；代码修改需重新编译并上传体验版，正式版需正常审核发布。手机验证首次同意、拒绝后仍可文字记账、再次同意、相册选图、拍照、系统权限拒绝及图片识别。
