# 墨记

基于 uni-app、Vue 3、TypeScript 和 Pinia 的微信记账小程序前端。使用 **HBuilderX 标准项目目录**，直接导入本目录即可开发。微信 AppID：`wx0f90babab478b2b6`。

## 在 HBuilderX 中运行

1. 使用支持 Vue 3 的 HBuilderX 正式版，通过「文件 → 导入 → 从本地目录导入」选择 `frontend`，不要选择整个仓库或 `unpackage`。
2. 第一次运行先在此目录执行 `npm install`，安装项目依赖。
3. 在 HBuilderX 的「工具 → 设置 → 运行配置」中设置微信开发者工具路径，并在微信开发者工具的「设置 → 安全设置」中开启服务端口。
4. 在 HBuilderX 中选择「运行 → 运行到小程序模拟器 → 微信开发者工具」。编译目录为 `unpackage/dist/dev/mp-weixin`。
5. 微信开发者工具中使用拥有此 AppID 开发权限的微信账号登录。首次打开进入墨记登录页；「先体验一下」无需后端，「微信登录」需先运行 `backend/run.py`。前端不保存 AppSecret。

## 微信登录

登录页已接入真实微信登录，提供加载状态、失败提示和重试。「我的」提供登录入口、登录状态、账号称呼及退出按钮；再次启动会先请求后端校验保存的凭证，再恢复账号。退出时调用后端注销当前 token，网络失败会保留当前状态并提示重试；凭证过期或收到 401 后回到登录页。

默认后端地址为 `http://127.0.0.1:8000`，适合本机微信开发者工具与 PyCharm 联调。需要修改时，将 `.env.example` 复制为 `.env.local` 并配置 `VITE_API_BASE_URL`，重新编译生效。真机使用手机可访问的后端地址。本地 HTTP 调试需在当前开发者工具项目中配置域名校验，正式 `manifest.json` 仍保留 `urlCheck: true`。

登录后账单仍只保存在本机，尚未开启云端同步。体验数据保留在 `moji-demo-v1`；账号数据存入 `moji-user-v1:<用户ID>:ledger`，昵称也按用户隔离。首次登录进入空的日常账本，不自动导入体验账单；退出后恢复体验区，重新登录恢复对应账号的本地记录。页面栈和内存记录随账号切换而重建。多人账本仍是本地演示。

登录凭证按后端地址分别缓存，不打印 code 或 token。若开发工具热重载保留旧 store，清除**编译缓存**并重新编译，不需要清除数据缓存。接口契约见[微信登录说明](../backend/docs/wechat-login.md)。

2026-10-24 已通过微信开发者工具实际点击登录页和「我的」入口完成真实登录，验证冷启动恢复、界面退出、退出后 token 返回 401，以及原有体验账单未被改写。登录逻辑另有 `npm run check:auth` 的十项自动检查，覆盖失败重试、401、离线、账号切换、存储不足和迟到响应。

如 HBuilderX 提示缺少 Sass 编译插件，按提示安装。建议使用与本项目锁定的 uni-app CLI 编译器相同或更新的 HBuilderX 正式版；构建依赖以 `package-lock.json` 为准。

## 目录结构

```text
frontend/
├── common/              # 类型、金额与日期工具、演示数据、公共样式
├── components/          # 导航、账单列表、图表和弹层等组件
├── pages/               # 登录、明细、统计、账本、我的、记一笔、墨记助手、日历、多人账本
├── static/              # 本地 SVG 图标，不依赖远程图片
├── store/               # Pinia 状态和本地存储
├── unpackage/           # HBuilderX / CLI 编译产物，不提交版本控制
├── scripts/             # 可选 CLI 构建与图标生成工具
├── App.vue
├── main.js              # HBuilderX 标准启动入口，业务代码使用 TypeScript
├── manifest.json        # 微信 AppID 在 mp-weixin.appid 中配置
├── pages.json
├── package.json
└── uni.scss
```

`manifest.json` 顶层 `appid` 是 HBuilderX 生成的 DCloud 应用标识，并非微信 AppID。微信 AppID 已配置在 `mp-weixin.appid`。

## 已实现的本地交互

- 明细：月份与账本切换、收入/支出切换、分类筛选、备注/账户搜索。
- 消费日历：从明细标题右侧「日历」进入，支持「全部、支出、收入」三种模式，默认同时展示每天的支出（−）和收入（+）。切换模式后，月汇总、日格、当日明细和无记录提示同步变化；支出与收入分别按整数分汇总，不相互抵减。支持月份与账本切换、回到今天、按选定日期补记，收入模式补记默认选择收入。无对应记录显示「—」，大额日格使用缩写，精确金额在当日明细中查看。
- 记账：自定义金额键盘、分类、日期、账户、账本、备注；新增、编辑、确认删除。
- 统计：分类环形图、日均金额、七日趋势和分类排行；数据与本地账单同步。
- 账本：账本切换、新建账本、独立收支与预算。
- 多人账本：从「我的账本 → 多人账本」进入，创建共同账本，体验家庭示例与受邀加入，查看共同收支、成员及各成员的记录，预览、重新生成或撤销演示邀请。创建者可移出普通成员并设置共同预算；普通成员仅维护自己的账单。移出成员会保留历史账单和记账人，并撤销该账本现有演示邀请。共同账单不允许转移到其他账本。
- 我的：微信登录入口与状态、账号称呼、退出登录、预算、分类、CSV 导出和帮助；体验模式可恢复演示数据。
- 墨记助手：一句话记账和聊天分析两个页面模式，从首页、记账页或统计页进入。

## 墨记助手静态演示

首页新增「一句话记账」和「聊聊花费」入口，助手内可随时切换模式。当前没有调用大模型，也没有发送数据到外部服务。

- 一句话记账：选择早餐、多笔消费或兼职收入示例，再点击「识别账单」生成预置草稿。支持修改金额、收支类型、分类、日期、时间、账户和备注，逐笔确认、批量确认或忽略。确认后写入现有本地账本，明细、统计和 CSV 导出同步更新，已确认的草稿不会重复保存。
- 示例「今天早上八点吃早餐8块钱」包含 `08:00` 时间。未给出时间的账单不补造时间，未给出账户时明确使用默认账户。现有账单兼容可选时间字段。
- 聊天分析：点选示例问题，展示当前账本的分类占比、分类明细、月度对比、超过200元的支出和消费提示。回答根据真实的本地账单计算，连续追问可继承分类范围。统计页进入时保留所选月份，首页进入时使用当前月份。
- 任意自然语言识别与自由聊天等待后端接入，未支持的输入会说明演示范围，不伪造模型回答。对话仅保留在本次页面中，切换助手模式会保留内容，离开后重新进入则开始新对话。

演示逻辑位于 `common/assistant-demo.ts`，交互组件位于 `components/assistant/`。后续使用 Python + FastAPI + PostgreSQL + Redis 后端接入 sub2api，数据库与 Redis 复用 z11 上的现有服务，按项目根目录的[项目方案说明](../项目方案说明.md)实施。

首次运行以当天为基准生成演示账单。此后读写本地存储，不会反复填充或重置数据。金额以整数分保存。当前账户仅是账单标签，不管理资金余额；预算为各账本的固定月预算。

**微信登录已接入，云端账单同步及其他业务 API 尚未接入，多人账本仍是本地演示，不能发送有效的跨用户邀请。** 示例家人与邀请不是实际用户；示例只在主动体验时创建，不修改现有个人账本，重复体验不重复添加数据。旧本地账单保留在体验区。记账数据仍保存在设备上，清理存储或卸载会丢失数据；体验模式中的「恢复演示数据」仅覆盖体验区记录。真实共享的身份、权限与邀请约定见[多人账本需求](../docs/多人账本需求.md)。

## 可选的命令行检查

这些命令与 HBuilderX 使用同一份根目录源码，仅作为构建验证和辅助预览，无需将项目改成 `src` 目录结构。

```powershell
npm install
npm run type-check
npm run check:auth
npm run check:assistant
npm run check:calendar
npm run check:shared-books
npm run dev:mp-weixin
npm run build:mp-weixin
```

开发模式输出 `unpackage/dist/dev/mp-weixin`，发布构建输出 `unpackage/dist/build/mp-weixin`，可手动导入微信开发者工具。H5 仅辅助检查移动布局，微信开发者工具和真机才是小程序验收环境。

```powershell
npm run dev:h5
npm run build:h5
```

本地图标可通过 `npm run generate:icons` 重新生成。
