# 墨记

基于 uni-app、Vue 3、TypeScript 和 Pinia 的微信记账小程序前端。使用 **HBuilderX 标准项目目录**，直接导入本目录即可开发。微信 AppID：`wx0f90babab478b2b6`。

## 在 HBuilderX 中运行

1. 使用支持 Vue 3 的 HBuilderX 正式版，通过「文件 → 导入 → 从本地目录导入」选择 `frontend`，不要选择整个仓库或 `unpackage`。
2. 第一次运行先在此目录执行 `npm install`，安装项目依赖。
3. 在 HBuilderX 的「工具 → 设置 → 运行配置」中设置微信开发者工具路径，并在微信开发者工具的「设置 → 安全设置」中开启服务端口。
4. 在 HBuilderX 中选择「运行 → 运行到小程序模拟器 → 微信开发者工具」。编译目录为 `unpackage/dist/dev/mp-weixin`。
5. 微信开发者工具中使用拥有此 AppID 开发权限的微信账号登录。首次打开直接进入账本首页，无需登录或后端即可体验本地记账、统计和日历；用户可从「我的」主动选择微信登录，本地联调登录需先运行 `backend/run.py`。前端不保存 AppSecret。

登录页已接入真实微信登录，提供加载状态、失败提示和重试。「我的」提供用户主动点击的登录入口、登录状态、账号称呼及退出按钮；无凭证启动不会调用微信登录或要求获取手机号、头像、昵称。有保存凭证时会先请求后端校验，再恢复账号。退出时调用后端注销当前 token，网络失败会保留当前状态并提示重试；退出、凭证过期或收到 401 后回到本地体验首页，不强制打开登录页。用户主动打开登录页后可选择「暂不登录，继续体验」返回浏览。

### 登录审核整改验收

1. 清除小程序缓存后冷启动，默认页面为 `pages/ledger/index`，直接显示账本与体验提示，不弹出登录或个人信息授权。
2. 不登录即可浏览明细、统计、账本和消费日历，手动新增、编辑、删除本地账单，体验助手示例。
3. 从「我的」主动点击「登录墨记」才进入登录页，点击「微信登录」才发起登录；选择「暂不登录，继续体验」可返回浏览。
4. 共享邀请先展示邀请内容，只有用户点击加入时才引导未登录用户登录。普通分享卡片默认打开账本首页。
5. 登录后退出、凭证过期或接口返回 401 时，清除当前账号内存并回到本地体验；登录页自身保留用户自主重试入口。登录账号与体验记录分别保存，体验记录不会自动上传。

### 微信转发

所有页面均在页面层注册 `onShareAppMessage`，支持右上角「… → 转发给朋友」。普通分享使用固定标题、首页路径和品牌封面，不携带当前账本、账单、对话或邀请参数，也不使用当前页面截图。共同账本中，只有创建者主动点击「发送微信邀请」且邀请仍有效时才发送账本邀请；右上角菜单仍分享小程序首页。

分享事件属于小程序前端，修改后需要重新编译、上传并发布小程序，更新后端不会替换已发布的小程序代码。微信中仍需实际验证分享卡片、接收后打开首页及家庭邀请加入流程。检查命令为 `npm run check:share`；小程序构建后可执行 `node scripts/check-share.mjs --build` 验证全部页面的原生分享钩子与封面产物。

重新提交审核时可填写：已将默认启动页调整为账本首页，用户无需登录即可浏览明细、统计、账本和消费日历，并体验本地记账。微信登录仅在用户主动选择账号功能时发起，支持取消并继续体验；登录不获取手机号、头像或昵称。

后端地址由 `common/config.ts` 中的 `appConfig` 统一管理，通过 `uni.getAccountInfoSync()` 识别微信小程序的运行版本：

| 运行版本 | 后端地址 |
| --- | --- |
| 发行构建（`build:mp-weixin`、`build:h5`） | 始终使用 `https://mjzs.zf-yun.cn`，不受微信运行版本影响 |
| 开发构建且明确为 `develop`（开发版） | 本地开发地址，默认 `http://127.0.0.1:8000` |
| 开发构建中的 `trial`（体验版）、`release`（正式版）、未知版本 | `https://mjzs.zf-yun.cn` |
| 微信版本信息缺失或读取失败 | `https://mjzs.zf-yun.cn`，不回退到 localhost |
| 非微信平台的开发构建 | 使用本地开发地址 |

前端无需 `.env` 文件，开发地址和正式地址直接在 `common/config.ts` 的 `DEV_BASE_URL` 与 `PROD_BASE_URL` 中配置，修改后重新编译生效。默认开发地址适合本机微信开发者工具与 PyCharm 联调；真机开发需改为手机可访问的本地开发服务器地址。发行包始终使用正式域名，避免审核环境信息异常或开发工具运行发行包时误连手机自身的 `127.0.0.1`。

本地 HTTP 调试需在当前开发者工具项目中配置域名校验，正式 `manifest.json` 仍保留 `urlCheck: true`。体验版和正式版需在微信公众平台将 `https://mjzs.zf-yun.cn` 添加为 request 合法域名。

### 登录连接失败与重新提审

登录页出现「暂时连接不到服务」表示 `uni.request` 进入了网络失败回调；这条提示本身无法区分合法域名、证书、DNS、超时或接口地址错误，不能直接认定账号无权限或后端停机。现在网络失败会区分域名、TLS、超时与其他连接失败，开发者工具控制台只记录运行环境、接口地址、去掉查询参数的路径与失败类别，不输出 code、token 或请求体。HTTP 业务错误继续使用后端返回的提示。

1. 在微信公众平台「开发管理 → 开发设置 → 服务器域名」核对 **request 合法域名**为 `https://mjzs.zf-yun.cn`，不包含 `/api/v1` 等路径；业务域名、uploadFile 域名与本地关闭域名校验不能替代这项配置。参考[腾讯云开发官方排查说明](https://docs.cloudbase.net/en/recipes/fix-auth-wechat-miniprogram)。
2. 执行 `npm run build:mp-weixin`，上传 `unpackage/dist/build/mp-weixin` 中的新发行包。新包的 `common/config.js` 应只使用正式接口地址；审核页面路径为 `pages/ledger/index`。
3. 在手机上打开新体验版，关闭开发调试，分别通过 Wi-Fi 和移动网络验证：首页免登录浏览 → 我的 → 微信登录 → 账本与统计正常加载 → 退出后继续体验。已有缓存需先导出需保留的本地体验记录，再按需清理缓存重测；不要仅以开发者工具调试成功作为审核环境验收结果。
4. 如需提交完整录屏，使用这次真机体验版实际运行过程，展示自主登录与核心功能；录屏不能替代修复网络连接失败。

2026-11-02 排查结果：用户确认已配置完整 request 合法域名；正式健康接口返回 200，直连 HTTPS 与 TLS 1.2 探测成功，证书链校验通过。首次发现本机工具私有配置为 `urlCheck: false` 后，已将发行目录的私有配置改为 `true` 并重新验证：无关域名返回 `url not in domain list`，正式域名的健康接口、真实微信登录及账本读取均返回 200，诊断会话已注销。用户另反馈手机体验版在关闭调试后，Wi-Fi 和移动网络均可正常登录。这确认了当前开发者工具中的域名校验和登录链路，并记录了用户的真机验证结果；**尚未确认审核方设备和原提审包运行地址**，不能仅据此认定审核问题已经解决。发行地址选择与网络错误分类由 `npm run check:network` 自动检查覆盖。

登录后个人及共享账本、账单和预算保存在云端，页面进入或返回前台会重新读取，也可下拉或手动刷新；请求失败不转成本地保存，暂不提供离线写入。体验数据保留在 `moji-demo-v1`；云端缓存使用 `moji-cloud-v1:<后端地址>:<用户ID>:ledger`。原 `moji-user-v1:<用户ID>:ledger` 保留原样，如有记录，「我的」提供旧记录 CSV 导出，不自动上传。首次登录创建空的日常账本，退出后恢复体验区。共享邀请、成员权限及生命周期已部署正式后端，登录账号不生成模拟成员或账单，详见[共享账本说明](../backend/docs/shared-books.md)。

登录凭证按后端地址分别缓存，不打印 code 或 token。若开发工具热重载保留旧 store，清除**编译缓存**并重新编译，不需要清除数据缓存。接口契约见[微信登录说明](../backend/docs/wechat-login.md)。

## 已实现的交互

- 明细：月份与账本切换、收入/支出切换、分类筛选、备注/账户搜索。
- 消费日历：从明细标题右侧「日历」进入，支持「全部、支出、收入」三种模式，默认同时展示每天的支出（−）和收入（+）。切换模式后，月汇总、日格、当日明细和无记录提示同步变化；支出与收入分别按整数分汇总，不相互抵减。支持月份与账本切换、回到今天、按选定日期补记，收入模式补记默认选择收入。无对应记录显示「—」，大额日格使用缩写，精确金额在当日明细中查看。
- 记账：自定义金额键盘、分类、日期、账户、账本、备注；新增、编辑、确认删除。
- 统计：分类环形图、日均金额、七日趋势和分类排行；数据与当前账单同步。
- 账本：账本切换、新建账本、独立收支与预算。
- 多人账本：从「我的账本 → 多人账本」进入，创建共同账本，体验家庭示例与受邀加入，查看共同收支、成员及各成员的记录，预览、重新生成或撤销演示邀请。创建者可移出普通成员并设置共同预算；普通成员仅维护自己的账单。移出成员会保留历史账单和记账人，并撤销该账本现有演示邀请。共同账单不允许转移到其他账本。
- 我的：微信登录入口与状态、账号称呼、退出登录、预算、分类、CSV 导出和帮助；体验模式可恢复演示数据。
- 墨记助手：一句话记账和聊天分析两个页面模式，从首页、记账页或统计页进入。

## 可选的命令行检查

这些命令与 HBuilderX 使用同一份根目录源码，仅作为构建验证和辅助预览，无需将项目改成 `src` 目录结构。

```powershell
npm ci
npm run check
npm run dev:mp-weixin
npm run build:mp-weixin
```

`npm run check` 依次运行 TypeScript、网络、登录、`check:chat`、`check:chat-v2`、`check:chat-cards`、助手示例、连续记账、日历及共享账本检查；任一失败立即停止并返回非零退出码。聊天检查分别为 12 组旧协议、22 组 V2 和 4 组真实 Vue 卡片渲染/阅读检查，使用模拟事实、服务或内存数据；云端共享检查现为 9 组，包含账单引用和权限重读。各单项命令仍可独立运行。共享账本检查复用 `scripts/test-modules.mjs` 递归解析本地模块及 `@/` 别名，新增依赖无需逐项手写替换。

在仓库根目录执行 `.\scripts\check.ps1` 可统一检查前后端，追加 `-Build` 同时验证微信小程序和 H5 构建，前置依赖和真实集成验证说明见[项目说明](../README.md#开发与检查)。

开发模式输出 `unpackage/dist/dev/mp-weixin`，发布构建输出 `unpackage/dist/build/mp-weixin`，可手动导入微信开发者工具。H5 仅辅助检查移动布局，微信开发者工具和真机才是小程序验收环境。

```powershell
npm run dev:h5
npm run build:h5
```

本地图标可通过 `npm run generate:icons` 重新生成。

### 小程序提示模块缺失或页面未注册

如果出现 `module 'common/config.js' is not defined`，并伴随 `Component is not found`、`Page "pages/login/index" has not been registered yet`，先处理最早出现的模块加载错误，页面和组件错误可能是后续连锁反应。

当前请求模块为 `common/api/request.ts`，编译后引用 `common/config.js`；若错误堆栈仍出现旧路径 `common/api.js` 或 `common/auth.js`，说明正在加载旧产物。先停止当前编译任务，在 `frontend` 目录执行 `npm run dev:mp-weixin`，等待 `Build complete`，再让微信开发者工具打开 `unpackage/dist/dev/mp-weixin`。也可以在 HBuilderX 停止运行后重新「运行到微信开发者工具」。

确认导入目录下存在 `common/config.js`、`common/api/request.js` 和 `pages/login/index.js`。若工具仍报告旧路径，清除微信开发者工具的**编译缓存**后重新编译；无需清除数据缓存，本地账单保存在其中。不要手动在源码中补建 `config.js`，它由 `common/config.ts` 编译生成。

登录页正常显示后，若出现 `127.0.0.1:8000 ... ERR_CONNECTION_REFUSED`，需启动本地后端 `backend/run.py`，并确认开发地址和服务监听端口一致。
